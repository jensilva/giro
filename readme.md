# 📦 TypeScript + Bootstrap Vanilla Project

Um projeto simples usando TypeScript, Bootstrap 5 e HTML5 vanilla com servidor local.

## 🚀 Começando

### Pré-requisitos
- Node.js (v16 ou superior)
- npm

### Instalação

1. **Instale as dependências**
```bash
npm install
```

### Inicie o servidor BE

2. **Inicie o servidor mock dos dados**
```bash
npx http-server
```

### Inicie o servidor FE

3.**Instale as dependências**
```bash
npm run serve
```


O projeto estará disponível em http://localhost:8080
